# 7A $\mathcal{L}^p(\mu)$

### 7.3 Definition
Suppose $(X, S, \mu)$ is a measure space and $0 < p \leq \infty$. The Lebesgue space $\mathcal{L}^p(\mu)$, sometimes denoted $\mathcal{L}^p(X, S, \mu)$, is defined to be the set of $S$-measurable functions $f: X \to F$ such that $\left\| p \right\|_p < \infty$.
